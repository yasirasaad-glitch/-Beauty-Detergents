# ميس الريم للمبيعات — النسخة 2
تطبيق Android Native (Kotlin + Jetpack Compose) يعمل محلياً بدون إنترنت.

## الوظائف
- إضافة عدد غير محدود من المنتجات.
- سعر وحجم وتكلفة لكل منتج.
- عروض مرنة لكل منتج بصيغة مثل 15+1,25+2,50+5.
- تفعيل/إيقاف وحذف المنتجات.
- تسجيل طلب باسم الزبون والمندوب.
- احتساب الهدية وقيمة الفاتورة تلقائياً.
- حفظ المنتجات والطلبات محلياً على الهاتف.
- تقرير إجمالي المبيعات والمجاني وسجل الطلبات.

## ملاحظة
هذه نسخة أولية محلية. نظام تسجيل الدخول الحقيقي، قاعدة البيانات المركزية، مزامنة عدة هواتف، التحصيلات، المخزون، وصلاحيات المدير/المندوب الكاملة تحتاج Backend في مرحلة لاحقة.
